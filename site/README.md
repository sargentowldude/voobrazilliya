# ВообразилЛиЯ — детские праздники в Кемерово

Node.js/Express-сайт, собранный по `DESIGN (1).md` и рекламной структуре из `semantic-core-kemerovo.md`.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://localhost:3000`.

## Готовые страницы

- `/` — организация детских праздников;
- `/animatory/` — аниматоры;
- `/animatory-na-dom/` — аниматоры на дом;
- `/detskiy-den-rozhdeniya/` — день рождения под ключ;
- `/show/` — интерактивные шоу;
- `/spektakli/` — выездные спектакли.
- `/afisha/` — публичная афиша;
- `/admin/` — управление афишами.

Все страницы имеют отдельные Title, Description, H1 и рекламные формулировки.

## Заявки

Формы отправляют `POST /api/leads`. Сервер валидирует данные и записывает заявки построчно в `data/leads.jsonl`. Файл исключен из Git. Перед production-запуском этот адаптер следует заменить отправкой в CRM, почту или базу данных.

Необходимо заменить тестовые телефон и email в `server.js`, разместить политику конфиденциальности и указать реальный `SITE_URL`.

## Афиши и админка

Афиши хранятся в `data/events.json`. В `/admin/` можно создавать и редактировать события, менять дату, описание, slug, цвет, изображение и статус публикации. Изображения сохраняются в `public/uploads/`.

Для локального запуска пароль — `tema-admin`. Перед публикацией обязательно задайте `ADMIN_PASSWORD` и `ADMIN_COOKIE_SECRET`.

Рекомендуемая будущая модель: `events`, `programs`, `characters`, `leads`, `users`, `media`. Для админки потребуются авторизация, роли, загрузка изображений, черновики и журнал изменений.

## Production

```bash
npm run check
npm start
```

Переменные окружения:

- `PORT` — порт приложения, по умолчанию `3000`;
- `SITE_URL` — публичный адрес для canonical-ссылок.
- `ADMIN_PASSWORD` — пароль входа в админку;
- `ADMIN_COOKIE_SECRET` — секрет подписи административной сессии.
- `TELEGRAM_LEADS_PROXY_URL` — HTTPS-адрес relay-сервиса для новых заявок;
- `TELEGRAM_LEADS_PROXY_SECRET` — общий секрет, который сервер передаёт relay в заголовке `X-Lead-Proxy-Secret`.

Файл `.env` уже исключён из Git; безопасный шаблон лежит в `.env.example`.

### Telegram relay

Когда будет готов relay, укажите его HTTPS-адрес и общий секрет в `.env`. После сохранения заявки сайт отправит на relay JSON вида `{ "event": "lead.created", "lead": { ... } }`. Сам relay должен пересылать сообщение в Telegram — токен бота и chat ID остаются только там, а не на сайте. Если переменная `TELEGRAM_LEADS_PROXY_URL` пуста, сайт продолжает сохранять заявки только в `data/leads.jsonl`.
